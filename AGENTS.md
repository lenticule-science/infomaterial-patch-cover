# Infomaterial Patch Cover

This settlement is one pure cover-assembly die. It consumes a canonical shallow
directory-plate receipt and an explicit mount-to-observation binding for every
direct mount. It has no filesystem capability.

It verifies all canonical RMN identities and kinds, then computes the same
placement-neutral directory material root obtained by recursive observation.
Every plate mount occurs exactly once; no nested receipt can overlap it because
the plate fixes the direct frontier.

It does not observe a directory plate, infer bindings from paths, schedule
workers, read child interiors, synthesize circuits, or certify enterprises.
